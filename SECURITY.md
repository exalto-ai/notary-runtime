# Security

Report suspected vulnerabilities to **[security@exalto.ai](mailto:security@exalto.ai)**.
Please do not open a public issue with vulnerability details before we have had
an opportunity to investigate and coordinate disclosure.

Include the affected version or commit, platform, expected and observed
behavior, and minimal reproduction steps using synthetic data where possible.
Do not send provider credentials, signing keys, vault secrets, or private
`.llmcapture` files. These checkpoints can reconstruct the original request,
including its credentials. Redact sensitive content from logs and screenshots.

This project is pre-release. Security fixes target the current release and
`main`; older versions do not have a separate security maintenance commitment.
Reports about the runtime, desktop application, protocol, or Exalto’s hosted
service can all use the same address.
